**README description:**

Dark Tab is a Chrome extension that makes any website easy on the eyes. Turn dark mode on or off with one click or with the shortcut Alt + Shift + D. It skips sites that are already dark, lets you exclude any site you choose, and has brightness and contrast sliders so you can adjust the look to your taste. Photos and videos keep their natural colors.

**Install:**
1. Download or clone this repository.
2. Open `chrome://extensions` and turn on Developer mode.
3. Click Load unpacked and select the project folder.
